# 花花智能建模-C4D端 v1.2.58

本次包含 v1.2.25 至 v1.2.58 的累计改进。

## 更新内容

- 智能吊顶：铝方通、平顶、方格板、跌级灯槽四种模式，支持墙体范围识别、可编辑边界样条及异形范围。
- 吊顶支持顶板与侧面封闭、周边射灯、平顶阵列射灯、方格发光灯板、长条灯分段与异形区域排布。
- 跌级吊顶支持内藏灯槽、挡光沿、向上洗光、中央灯带、线性风口；中央灯带长度、宽度和位置可独立调整。
- 按吊顶模式显示相关参数，优化射灯网格和生成缓存。
- 智能楼梯增加多层总控、平台分边围栏、墙体连续连接、踢脚线和顶部封顶；新增木扶手玻璃护栏并优化转角连接。
- 智能门窗支持多对象批量生成、默认复用材质及可选独立材质。
- 新增单格/双格、玻璃门/铁皮门消防柜及预览，优化内部器件、门缝、连接及中英文标识。
- 保持授权、machineId、CDK、AI JSON 导入及模型库逻辑不变。

## 安装与更新

Windows：关闭 Cinema 4D，运行 `HuahuaC4DPlugin-v1.2.58.exe`，选择 C4D 版本，安装后重启。

macOS 或手动安装：解压 `HuahuaC4DPlugin-v1.2.58-manual.zip`，将其中 `HuahuaC4DPlugin` 文件夹的内容放入 C4D 插件目录中同名文件夹，安装后重启。ZIP 是手动安装包，不是 macOS 安装程序。

**请先保存场景并备份原插件。旧场景中 Python 生成器内嵌代码不会自动升级，新增参数需要重新生成对象。**

安装包包含主插件、吊顶模块、几何依赖及 MIT 许可证、17 张预览图和消防柜标识，不包含授权 token、machine_id.json、用户配置、模型或贴图。
