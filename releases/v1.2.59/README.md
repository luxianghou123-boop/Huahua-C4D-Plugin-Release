# 花花智能建模-C4D端 v1.2.59

## 更新内容
- 修复跌级吊顶空调格栅上方及侧面漏光：增加不透明遮光背板与四周封边，接缝搭接封闭。
- 保留底部格栅外观、风口尺寸调节及现有吊顶功能。
- 包含 v1.2.58 全部功能，不更改授权或 AI 面板逻辑。

## 安装与更新
Windows：保存场景并关闭 C4D，运行 `HuahuaC4DPlugin-v1.2.59.exe`。

macOS 或手动安装：解压 `HuahuaC4DPlugin-v1.2.59-manual.zip`，将 HuahuaC4DPlugin 内文件更新至原插件同名目录，重启 C4D。

请先备份原插件。旧场景的 Python 生成器内嵌代码不会自动更新，需要重新生成吊顶才能应用修复。
