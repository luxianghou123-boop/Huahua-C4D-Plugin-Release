# 花花智能建模-C4D端 v1.2.60

## 更新内容
- 智能门窗、消防柜、楼梯及墙体适配吊顶增加持久材质引用，避免清理未使用材质时误删生成器材质。
- 更换、清空材质链接时同步引用，保留分区材质，不新建额外材质球。
- 包含 v1.2.59 风口遮光修复，不修改授权或 AI 面板逻辑。

## 安装
保存场景并关闭 C4D。Windows 运行 EXE；macOS 使用 manual.zip，将 HuahuaC4DPlugin 内文件更新至原插件同名目录，然后重启。
请先备份原插件。旧生成器内嵌代码不会自动升级，需要重新生成对象；已经删除的材质无法自动恢复。

## 验证范围
17 个门窗与消防柜预设通过 C4D 原生材质清理测试，材质替换、保存重载和重复加载检查通过。
楼梯及墙体适配吊顶接入相同保护，尚未逐款原生回归。Windows 安装包已生成，未做 Windows 原生端到端安装测试。
安装包不含授权凭据、用户配置或模型库。SHA256 见 checksums.txt。
